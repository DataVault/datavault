# DataVault Swagger / OpenApi files

The Swagger/OpenAPI files for DataVault WebApp and DataVault Broker are dynamically generated from the code.

They will contain `version` and `x-generated` fields. Note the version contains the <i>git commit hash</i>.

      version: 0.0.1-SNAPSHOT (f5b8924)
      x-generated-at: 2022-03-29T14:15:16.101

## Static Files
This directory contains pre-generated WebApp API and Broker API files.

    databvault-webapp-openapi.yaml
    databvault-broker-openapi.yaml

## OpenApi / Swagger file generation
These files can be regenerated by running these two tests. These tests are generally disabled as the generated files will be different on each run due to timestamp data.

    org.datavaultplatform.webapp.app.setup.OpenApiWebAppTest.testOpenApiAsYaml

    org.datavaultplatform.broker.actuator.OpenApiBrokerTest.testOpenApiAsYaml

If you run the script ```SWAGGER_OPENAPI/generateSwaggerFiles.sh``` that will run these two test methods and generate the 2 openapi/swagger files from the latest code.

## Dynamic Files
For both the Broker and the WebApp, the applications will expose dynamically generated Swagger/OpenAPI at runtime via this endpoint.

    http://<host>:<port>//v3/api-docs.yaml
